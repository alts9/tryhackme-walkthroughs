##### Task 4 - System-Level Threats
1. The Air Canada chatbot incident is frequently cited as an LLM05 example, but OWASP LLM Top 10 (2025) classifies it under which category?
	- `LLM09`

	- `Excessive Functionality, Excessive Permissions, Excessive Autonomy`
3. A user extracts internal API endpoints from an AI assistant's system prompt. Which OWASP LLM Top 10 (2025) category does this fall under?
	- `LLM07`

	- `LLM10`
