##### Task 4 - Machine Learning Algorithms
1. Which category of ML algorithm learns by receiving rewards or penalties based on actions taken in an environment?
	- `Reinforcement learning`
2. Which category of ML algorithm uses a small amount of labelled data to guide learning across a larger unlabelled dataset?
	- `Semi-supervised learning`
3. What's the flag?
	- Open agent, You will be given four missions and asked to categorize ML method used in each, along with your reasoning.
		1. A system trained on thousands of labelled network logs, each marked either malicious or benign, to classify future traffic.
			- `Supervised learning because it trains of labelled data`
		2. An algorithm analysing years of user behaviour data with no labels attached, tasked with grouping users into clusters based on patterns it finds itself.
			- `Unsupervised learning because it works with unlabelled data`
		3. A fraud detection model trained on a small batch of confirmed fraud cases and a much larger pool of unlabelled transactions.
			- `Semi-supervised learning because it uses a small portion of labelled data to guide larning process`
		4. An autonomous penetration testing agent that learns which actions lead to successful exploitation by receiving a score after each attempt.
			- `Reinforcement learning because it received reward or penalty during each attempt`
